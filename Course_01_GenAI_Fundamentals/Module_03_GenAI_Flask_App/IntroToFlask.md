# Introduction to Flask
* Flask is a micro web framework
* Flask 2.2.2 runs on Python 3.7 and newer
* comes with a minimal set of dependencies
* Community-maintained extensions
## Main features
* Built-in web server
* Has a deugger
* Uses a standard python logging
* Has built-in unit testing
* Enables request and response classes
## Additional features
* Provides static asset support
* Provides dynamic templates
* Supports routing:
**  Dynamic URLs
  HTTP Methods
  Redirecting
* Enables error handling
* Support sessions
## Popular extensions
* Flask-SQLAlchemy
* Flask-Mail
* Flask-Admin
* Flask-Uploads
* Flask-CORS
* Flask-Migrate
* Flask-User
* Marshmallow
* Celery
## Installation
Install Flask Flask in the pip package v. 2.2.2
