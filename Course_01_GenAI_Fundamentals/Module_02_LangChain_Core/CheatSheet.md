| **CommaSeparatedListOutputParser** | A parser used to return a list of comma-separated items. | **LLMChain** | A basic chain from `langchain.chains` that combines a prompt template with an LLM. | `from langchain.chains import LLMChain`<br><br>`template = """Your job is to come up with a classic dish from the area that the users suggests.`<br>&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;`{location}`<br><br>&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;`YOUR RESPONSE:`<br>`"""`<br>`prompt_template = PromptTemplate(template=template, input_variables=['location'])`<br><br>`location_chain = LLMChain(`<br>&nbsp;&nbsp;&nbsp;&nbsp;`llm=mixtral_llm,`<br>&nbsp;&nbsp;&nbsp;&nbsp;`prompt=prompt_template,`<br>&nbsp;&nbsp;&nbsp;&nbsp;`output_key='meal'`<br>`)`<br><br>`result = location_chain.invoke(input={'location':'China'})` |
| **SequentialChain** | A chain from `langchain.chains` that combines multiple chains in sequence, where the output of one chain becomes the input for the next chain. | `from langchain.chains import SequentialChain`<br><br>`# First chain - gets a meal based on location`<br>`location_chain = LLMChain(`<br>&nbsp;&nbsp;&nbsp;&nbsp;`llm=mixtral_llm,`<br>&nbsp;&nbsp;&nbsp;&nbsp;`prompt=location_prompt_template,`<br>&nbsp;&nbsp;&nbsp;&nbsp;`output_key='meal'`<br>`)`<br><br>`# Second chain - gets a recipe based on meal`<br>`dish_chain = LLMChain(`<br>&nbsp;&nbsp;&nbsp;&nbsp;`llm=mixtral_llm,`<br>&nbsp;&nbsp;&nbsp;&nbsp;`prompt=dish_prompt_template,`<br>&nbsp;&nbsp;&nbsp;&nbsp;`output_key='recipe'`<br>`)`<br><br>`# Third chain - estimates cooking time`<br>`recipe_chain = LLMChain(`<br>&nbsp;&nbsp;&nbsp;&nbsp;`llm=mixtral_llm,`<br>&nbsp;&nbsp;&nbsp;&nbsp;`prompt=recipe_prompt_template,`<br>&nbsp;&nbsp;&nbsp;&nbsp;`output_key='time'`<br>`)`<br><br>`# Combine into sequential chain`<br>`overall_chain = SequentialChain(`<br>&nbsp;&nbsp;&nbsp;&nbsp;`chains=[location_chain, dish_chain, recipe_chain],`<br>&nbsp;&nbsp;&nbsp;&nbsp;`input_variables=['location'],`<br>&nbsp;&nbsp;&nbsp;&nbsp;`output_variables=['meal', 'recipe', 'time'],`<br>&nbsp;&nbsp;&nbsp;&nbsp;`verbose=True`<br>`)` |
