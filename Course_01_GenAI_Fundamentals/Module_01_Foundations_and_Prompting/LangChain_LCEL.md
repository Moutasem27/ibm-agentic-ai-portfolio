# LangChain LCEL Chaining Method
## What is LCEL?
* Builds apps using the pipe (|) operator
* Ensures a clean, readable flow of data
## NEW LCEL Pattern provides:
* Better composability
* Clearer visualization of data flow
* Greater flexibility when constructing complex chains
## What is needed to create an LCEL patter?
1. Define a template with variables in curly brackets {}
2. Create a PromptTemplate instance.
3. Build a chain using the pipe(|) operator to connect components.
4. Invoke the chain with input values.
