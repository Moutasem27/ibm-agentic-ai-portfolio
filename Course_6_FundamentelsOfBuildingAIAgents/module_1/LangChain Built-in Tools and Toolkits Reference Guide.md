# LangChain Built-in Tools and Toolkits Reference Guide


## 1. Overview of Tools and Toolkits
- **Tools:** Utilities designed to be called by a model where inputs are generated by models and outputs are passed back to models[cite: 1].
- **Toolkits:** Collections of tools meant to be used together[cite: 1].
- **Important Note:** Some tools are free while others require payment; always check the official documentation before deployment[cite: 1].
